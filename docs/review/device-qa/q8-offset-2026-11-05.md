# The offset along a direction

Read 2026-11-05 from `VecQ8.offset` on `ef68565`. No scale was changed. The scale and the circle test stay in [q8-scale-2026-11-04.md](q8-scale-2026-11-04.md). The roots stay in [integer-roots-2026-11-05.md](integer-roots-2026-11-05.md). The perpendicular stays in [daemon-query-2026-11-04.md](daemon-query-2026-11-04.md).

`Q8(units:)` multiplies by `Q8.scale`. `squared` is the raw value times itself. `lengthSquaredRaw` adds the two squared raw components. `distanceSquared` adds the squared raw deltas. `VecI.asQ8` builds `VecQ8(unitsX:unitsY:)`. `Circle.radiusQ8` is `Q8(units: radiusUnits)`.

`offset` takes `isqrt` of `lengthSquaredRaw`. A magnitude of 0 returns the same vector. Otherwise each component adds `mulDivHalfAway` of that direction component, `Int64(units) * Q8.scale`, and the magnitude.

This does not change a scale.
