VoiceOver reads `Restart`, `Share run summary`, and `Rehearse Court`. The outcome title and each card row become a sentence: the first letter is uppercased and the rest is lowercased.

A clock is spoken as a duration. `5:00` is five minutes. `0:01` is one second. `1:01` is one minute one second.
