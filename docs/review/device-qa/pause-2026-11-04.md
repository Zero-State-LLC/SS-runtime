# Pause

Read 2026-11-04 from `GameScene` on `93f6d67`. Pause still adds no tick.

`setPaused` sets `runPaused`, pauses the renderer root, clears the last display time, and resets the touch controller. The held stick and a pending dodge edge do not survive the boundary. `update` returns before hit-stop, the intro, and the simulation step.

An interruption raises pause only for a run that is already ticking: pause is not already on, the intro is absent, and the outcome is playing. The title, the terminal surface, the intro, and upgrade selection stay as they are.
