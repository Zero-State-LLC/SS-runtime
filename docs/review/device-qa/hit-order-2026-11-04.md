# Hit order

Read 2026-11-04 from `DamageHit` on `93f6d67`. The order was not changed.

`DamageHit.precedes` is the order for one tick's intersections. The earliest intersection time `t` comes first. On an equal time, a wall consumes the projectile: `isWall` wins. Then the lower target id. Then the lower projectile id, so two hits never compare equal. A wall's target id is `EntityID(0)`.

The pool index addresses a projectile. It is not a sort key. `ordered` sorts with `precedes`.

This is the one damage order. The 50 percent integrity scale stays in [player-integrity-2026-11-04.md](player-integrity-2026-11-04.md).
