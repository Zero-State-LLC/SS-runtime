# Run card

Read 2026-11-04 from `RunCard` on `30a2cc6`. No medal predicate was changed.

Elapsed ticks print as `m:ss` at 60 Hz. The seconds are `ticks / 60`, so a partial second is truncated. A success that is strictly shorter than the stored best prints `NEW BEST`. A success with no stored best, when the run may be stored, prints `NEW BEST` as well. Any other success prints `+` or `-` and the truncated gap to that best. A failure prints no ghost row.

The incident report says `SUBJECT EXTRACTED` for a success, `SUBJECT DETAINED` for a failure, and `REPORT VOID` otherwise. In that report, TIME is `TIME UNDER OBSERVATION` and CAMERAS is `CAMERAS TAMPERED WITH`. The medal names and the predicates stay in [medal-predicates-2026-11-03.md](medal-predicates-2026-11-03.md). The card lists only the medals a success earned.
