`isTerminal` is `blendOrTransition == "terminal"`. `frameIds(forDirection:)` returns every frame id when the clip lists no directions. Otherwise it keeps the ids that contain `_<direction>_`.

The catalog schema is `clip-metadata-001` or `clip-metadata-002`. The animation version is `animation-civic-seam-001`. An unexpected catalog key, a duplicate clip id, or a missing id from `ClipCatalog.requiredClipIds` refuses the file. A reduced-motion clip that differs from the clip id must itself be in the catalog. Schema `002` carries `timing`, with `unitsPerSecond` and one `frameUnits` entry per frame, in place of `framesPerSecond`. Schema `001` requires `framesPerSecond` above 0.

`fourDirections` are `n`, `e`, `s`, and `w`. `distinctEnemyAnticipateIds` are the five standard anticipate clips. Their states are unique, and each id is present. The four-direction roles are `player`, `fogAnalyticsCloud`, `cableCarCorrelator`, `sutroSignalWitch`, `autonomousInformant`, `victorianVendor`, and `algorithmicModerate`. A camera clip's directions are empty. A four-direction role's directions are exactly `n`, `e`, `s`, `w`.

When both `camera_field_off` and `camera_destroy` are present, both markers are `cameraDestroyed`, the field-off blend is `immediateOnEvent`, and the field-off cancel windows exclude `camera_destroy`. One of those clips missing skips that check. One anchor is stored per actor role. A second anchor on the same role refuses the clip.

A directionless clip's frame ids contain `_none_`. A directed clip gives every direction a non-empty frame set, those sets share one count, and the counts sum to the clip's frame count. A terminal clip's cancel windows are empty. Each window is a clip id, a state of that role, or one of `hurt`, `defeat`, and `dodge`. The load computes `durationTicks(at: 60)` for each listed direction, or for `none` when the clip lists none.
