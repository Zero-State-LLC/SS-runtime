# The lead on a shot

Read 2026-11-05 from `Targeting.aimVelocity` on `ef68565`. No speed was changed. The pulse speed stays in [civic-pulse-2026-11-04.md](civic-pulse-2026-11-04.md). Half-away stays in [q8-scale-2026-11-04.md](q8-scale-2026-11-04.md). `isqrt` and the discriminant stay in [integer-roots-2026-11-05.md](integer-roots-2026-11-05.md). A zero-length direct stays in [ricochet-continuation-2026-11-04.md](ricochet-continuation-2026-11-04.md).

The speed is `projectileSpeedPerTick * Q8.scale`. A non-nil intercept is returned. Otherwise `direct` is returned.

`direct` takes the raw offset. A zero `isqrt` returns `(speed, 0)`. Otherwise each component is `mulDivHalfAway` of that component, the speed, and the `isqrt`.

`intercept` uses the target velocity. `a` is `vx² + vy² − speed²`, `b` is `2 * (rx * vx + ry * vy)`, and `c` is `rx² + ry²`. `a == 0` and `b == 0` returns nil. When `a == 0`, `t` is `divHalfAway(-c, b)`, and `t <= 0` returns nil. Otherwise a nil discriminant returns nil. The two times are `divHalfAway` of `-b − isqrt` and `-b + isqrt`, each over `2 * a`. The smallest `t > 0` wins. No positive time returns nil.

The aim point adds `velocity * t / Q8.scale` to the relative position. That division truncates. It is not half-away. `direct` then runs from zero to that aim.

This does not change a speed.
