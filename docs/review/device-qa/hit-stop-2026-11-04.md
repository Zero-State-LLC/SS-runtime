# Hit-stop

Read 2026-11-04 from `HitStopClock` and `procedural-vfx-003` on `93f6d67`. No duration was changed.

Display rate is 60 frames per second. Frames that fit inside a duration are `milliseconds × 60 / 1000`. The standard cap is 50 ms, which is 3 frames. `captainTelegraph` and `bossPhaseBreak` use the 90 ms cap, which is 5 frames. The takedown freeze is 70 ms, which is 4 frames. A frozen frame does not step the simulation and does not consume a command. Impacts in one tick take the longest cap that applies. A freeze does not stack on another, because the simulation does not step while one is running.

A `playerHit` from the same source is skipped while that source is inside the last 15 ticks. The catalog allows 16 concurrent emitters. A full-screen white flash is forbidden. Shake amplitudes stay in [camera-follow-2026-11-03.md](camera-follow-2026-11-03.md).
