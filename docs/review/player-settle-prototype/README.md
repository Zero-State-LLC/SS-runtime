# Proposed source settling comparison

Two extreme releases (movement phases 5 and 13) now have 17 authored source samples over a proposed 0.5 seconds. The lower toe lands, remains fixed while the other foot settles, then lifts and steps to the common neutral. The opposite foot remains fixed during that step. Proposed lift is 3 source units. Neither timing nor lift is an accepted design constant.

Normal-speed.mp4 and quarter-speed.mp4 compare direct switch and settle for both phases. Static roots, source only. Existing narrow stance, asymmetric costume and material ownership retained. Exact first-frame movement and terminal neutral pixel equality verified. All sampled limb lengths, reach, nonnegative heel/toe heights and knee-below-hip checks pass. These checks do not prove weight transfer, full-sole contact or natural cadence.

Initial assembly assertion assumed 16 distinct cyclic frames and rejected the 17th terminal sample; corrected to the actual pose count. No production art, test fixtures or runtime behavior changed. Source recipes require the workspace's existing bounded source inputs. Copied auxiliary boot plates/reports are inherited diagnostics; proposal.json, pose arrays, export-checks.json and the new videos describe this experiment.
